Built for local privacy

Everything Cove remembers lives in ~/Library/Application Support/Cove on Mac or %LOCALAPPDATA%\Cove on Windows.

  • Tabs & layout

    Horizontal tabs with the address bar underneath. A slim sidebar docks left, right, or bottom, and collapses to icons.

  • Workspaces

    Separate workspaces that still share logins, each with its own color so you can tell them apart at a glance.

  • Ad & tracker blocking

    Built-in blocking by default, with a one-click allow when you need the current site unfiltered.

  • Local bookmarks & history

    Bookmarks, history, and downloads are stored locally. Nothing is uploaded or synced to a Cove account.

  • Password vault

    Passwords save only on this computer, locked with a Cove password, sign-in unlock, or Touch ID on Mac.

  • Memory aware

    A memory cap puts background tabs to sleep so Cove stays light while you keep a pile of tabs open.

  • Video focus

    Fullscreen video hides the sidebar and top bar. Hover a video to pop it out into its own window.

  • Unpacked extensions

    Load an unpacked extension folder that contains manifest.json. Cove runs its content scripts.
